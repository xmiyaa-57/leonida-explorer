# Leonida Explorer

Carte interactive personnelle de Leonida, basée sur le fond communautaire YANIS V18 publié par GTADB.ORG.

## Fonctionnalités

- Carte HD communautaire avec zoom et déplacement.
- Carte vierge au démarrage : aucun repère préchargé.
- Ajout de repères par clic sur la carte.
- Catégories et couleurs personnalisées.
- Modification et suppression des annotations.
- Sauvegarde automatique dans le navigateur.
- Export et import d'une sauvegarde JSON.

## Lancer le site

Le projet est un site statique. Active GitHub Pages dans **Settings → Pages**, en choisissant **Deploy from a branch**, branche **main**, dossier **/ (root)**. Après publication, le site sera accessible à l'adresse :

https://xmiyaa-57.github.io/leonida-explorer/

## Données personnelles

Les annotations sont conservées dans le stockage local du navigateur. Elles ne sont pas envoyées à un serveur. Utilise **Exporter** pour conserver une copie ou transférer tes repères vers un autre appareil.
